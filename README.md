# Product Dataset – Data Cleaning and Transformation

## Project Overview

This project focuses on cleaning and transforming a product dataset using Microsoft Excel. The main objective is to improve data quality, consistency, and readability.

## Tools Used
- Microsoft Excel

## Data Cleaning Tasks

1. **Missing Value Handling:** Identified and handled missing values appropriately.
2. **Find and Replace:** Corrected spelling mistakes and inconsistent text.
3. **Duplicate Removal:** Identified and removed duplicate records.
4. **Column Splitting and Merging:** Restructured columns to organize product information.
5. **Conditional Formatting:** Highlighted important data for better visualization.

## Project Results

- Original Records: 34
- Duplicate Records Removed: 3
- Final Unique Records: 31
- Improved data consistency and readability.
- Prepared the dataset for further analysis.

## Conclusion

This project provided practical experience in Excel-based data cleaning and transformation. It strengthened my understanding of data preparation techniques used in real-world data analytics.
